# Code of Conduct

Monero Farm Panel is an open-source project for people who want to build, operate, improve, document, test, or discuss self-hosted Monero mining infrastructure.

We want the project to stay practical, technical, welcoming, and safe for contributors with different levels of experience.

## Expected behavior

Be respectful and constructive. Discuss ideas, code, bugs, benchmarks, architecture, documentation, and operational choices without attacking the people behind them.

When reviewing code or reporting problems:

- explain what is wrong and, when possible, how to reproduce it;
- criticize the implementation, not the contributor;
- assume good intent unless there is clear evidence otherwise;
- keep technical disagreements focused on evidence, trade-offs, and maintainability;
- make room for beginners asking reasonable questions;
- avoid exposing private infrastructure details, credentials, wallet addresses, private keys, tokens, or other secrets in public issues and pull requests.

## Unacceptable behavior

The following is not acceptable in project spaces:

- harassment, threats, personal attacks, or discriminatory language;
- deliberate humiliation, trolling, or sustained disruption;
- publishing another person's private or identifying information without permission;
- knowingly submitting malicious code, credential-stealing logic, hidden miners, backdoors, or destructive behavior;
- encouraging unauthorized access to systems or mining on hardware without the owner's permission;
- repeatedly ignoring maintainer instructions intended to protect users, contributors, or project security.

## Security and sensitive reports

Do not publish credentials, secrets, private keys, wallet-sensitive information, or exploitable security details in a public issue.

For sensitive conduct or security concerns, contact the repository owner privately through their GitHub profile or another private contact channel published by the maintainer. Public GitHub issues should be used only when the report is safe to disclose publicly.

## Scope

This Code of Conduct applies to project-controlled spaces, including issues, pull requests, code review, documentation, discussions, release coordination, and other collaboration directly related to Monero Farm Panel.

It also applies when someone is officially representing the project in another public space.

## Enforcement

Maintainers may edit or remove comments, close or lock discussions, reject contributions, or restrict participation when behavior violates this policy.

Responses should be proportional to the situation. Minor problems should normally receive a clear correction request first; serious abuse, security violations, threats, or malicious contributions may result in immediate removal or blocking.

Maintainers are expected to apply these rules consistently and in the best interests of the project and its community.

## Project principle

Monero Farm Panel should remain useful to both experienced operators and people who are learning. Good contributions make the project easier to understand, safer to operate, and easier for the next person to improve.
