
# Monero Farm Panel — краткий справочник функций

Эта страница соответствует встроенному разделу **Документация** в интерфейсе.

## Fleet Health Score
Оценка здоровья каждого сервера и всей фермы по шкале 0–100. Учитываются доступность, статус XMRig, отклонение от базовой нормы, температура, rejected shares, сеть, синхронизация monerod и свежие ошибки.

## Предполагаемый доход
Панель автоматически показывает ориентировочный XMR/сутки и USD/сутки/30 дней. Расчёт использует текущий 60s-хешрейт фермы, network difficulty и награду последнего блока из monerod, а также XMR/USD. Это статистическая оценка, а не обещание дохода.

## XMRig Proxy
Если на сервере найден процесс `xmrig-proxy`, панель пытается найти его localhost HTTP API и показывает:
- версию и режим;
- суммарный hashrate;
- miners/workers;
- accepted/rejected/invalid;
- upstream connections;
- worker hashrate 1m/10m/1h/12h/24h.

API рекомендуется держать только на `127.0.0.1`.

### Установка из панели
Если XMRig Proxy не найден, в разделе **Прокси** и на карточке компонента появляется кнопка **Установить XMRig Proxy**. Панель:
- получает последний стабильный официальный GitHub Release;
- для Linux x86_64 скачивает официальный `linux-static-x64` архив;
- проверяет SHA256 релизного файла;
- создаёт `/etc/xmrig-proxy/config.json`;
- создаёт и включает `xmrig-proxy.service`;
- оставляет HTTP API только на `127.0.0.1:60051`;
- по умолчанию слушает Stratum на `0.0.0.0:3334`;
- не меняет существующий XMRig автоматически.

Upstream, wallet и password берутся из **Настройки → Майнинг**. Firewall панель автоматически не изменяет.

## P2Pool аналитика
Расширенная статистика использует официальный P2Pool Data API. Для неё P2Pool должен быть запущен с:

```text
--data-api /path/to/api --local-api
```

Панель автоматически определяет путь в аргументах процесса и читает:
- `local/stratum`;
- `pool/stats`;
- `network/stats`.

Показываются local hashrate 15m/1h/24h, shares found/failed, effort, workers, pool hashrate/miners/blocks и sidechain.

## Безопасное переключение XMRig на XMRig Proxy
После установки XMRig Proxy появляется кнопка **Перевести XMRig на XMRig Proxy**. Панель:
- проверяет, что `xmrig-proxy.service` запущен и порт 3334 слушается;
- блокирует потенциальную петлю, если upstream Proxy указывает на него же;
- делает backup текущего XMRig `config.json`;
- меняет только первый pool на `127.0.0.1:3334`;
- перезапускает настроенный XMRig/mining service;
- ждёт восстановления хешрейта;
- автоматически возвращает исходный config, если майнинг не восстановился.

Повторное нажатие безопасно: backend определяет, что XMRig уже использует Proxy, и не делает повторный restart.

## P2Pool аналитика в один клик
Если P2Pool работает без Data API, в **Компоненты → P2Pool аналитика** появляется кнопка **Включить P2Pool аналитику**. Панель автоматически добавляет официальный `--data-api` и `--local-api`, создаёт каталог данных, сохраняет изменение в systemd/startup script и перезапускает сервис. Перед изменением startup-файла создаётся backup; если P2Pool не возвращается с нужными флагами, изменение откатывается.
