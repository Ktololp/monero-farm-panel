# ✨ Monero Farm Panel v1.2 — справочник функций

Эта страница соответствует встроенному разделу **Документация** в интерфейсе и описывает основные функции стабильной версии **v1.2.0**.

## ❤️ Fleet Health Score

Панель считает оценку здоровья каждого сервера и всей фермы по шкале **0–100**.

В расчёт входят:

- доступность сервера по SSH;
- состояние XMRig;
- отклонение текущего хешрейта от личной базовой нормы;
- температура CPU;
- rejected shares;
- DNS/Internet;
- синхронизация monerod;
- свежие ошибки и проблемы компонентов.

`100` означает, что известные панели показатели выглядят здоровыми. Низкий score — повод открыть сервер и посмотреть предупреждения, компоненты и логи.

## 💰 Предполагаемый доход

Dashboard автоматически показывает ориентировочный доход фермы:

- **XMR / сутки**;
- **USD / сутки**;
- **USD / 30 дней**.

Расчёт использует:

```text
текущий 60s-hashrate фермы
× время
÷ network difficulty
× награду последнего блока
```

Для USD используется текущий XMR/USD.

> [!NOTE]
> Это статистическая оценка по текущим условиям сети. Она не учитывает удачу конкретного P2Pool-майнера, будущие изменения сложности/цены и не является обещанием выплаты.

## ⇄ XMRig Proxy

XMRig Proxy является полноценным компонентом панели. Если Proxy найден, панель пытается подключиться к его localhost HTTP API и показывает:

- версию и mode;
- суммарный hashrate;
- workers;
- miners now / max;
- accepted / rejected / invalid;
- active / total upstream connections;
- worker hashrate по временным окнам.

Рекомендуемая схема API:

```text
HTTP API: 127.0.0.1:60051
Stratum:  0.0.0.0:3334
```

### Почему hashrate Proxy может отличаться от XMRig

XMRig показывает фактическую скорость вычислений CPU/GPU за свои окна. XMRig Proxy оценивает скорость через принятые shares и собственные временные окна. Поэтому после запуска или при редких shares Proxy может некоторое время показывать больше или меньше XMRig.

Сравнивать лучше не одну мгновенную цифру, а устойчивое значение за более длинный интервал.

### Установка XMRig Proxy из панели

Если `xmrig-proxy` не найден, в разделе **XMRig Proxy** и на карточке компонента появляется кнопка установки.

Панель:

1. получает последний стабильный официальный GitHub Release XMRig Proxy;
2. для Linux x86_64 скачивает `linux-static-x64` архив;
3. проверяет SHA256 релизного файла;
4. устанавливает binary в `/opt/xmrig-proxy/`;
5. создаёт `/etc/xmrig-proxy/config.json`;
6. создаёт и включает `xmrig-proxy.service`;
7. оставляет HTTP API на `127.0.0.1:60051`;
8. по умолчанию слушает Stratum на `0.0.0.0:3334`;
9. **не переключает существующий XMRig автоматически**.

Upstream, wallet и password берутся из **Настройки → Майнинг**. Firewall панель автоматически не изменяет.

Повторная установка уже работающего Proxy безопасно блокируется.

Подробнее: [XMRIG_PROXY.md](XMRIG_PROXY.md).

## ⚡ Безопасное переключение XMRig на XMRig Proxy

После установки Proxy появляется кнопка **«Перевести XMRig на XMRig Proxy»**.

Перед изменением панель:

- убеждается, что Proxy работает;
- проверяет доступность порта `3334`;
- блокирует потенциальную петлю Proxy → Proxy;
- читает текущий XMRig `config.json`;
- определяет, не настроен ли уже `127.0.0.1:3334`.

Затем:

1. создаётся backup текущего XMRig config;
2. первый pool XMRig меняется на `127.0.0.1:3334`;
3. перезапускается настроенный mining/XMRig service;
4. панель ждёт возврата рабочего хешрейта;
5. если майнинг не восстановился, исходный config автоматически возвращается и сервис запускается повторно.

Типичный маршрут:

```text
XMRig → 127.0.0.1:3334 → XMRig Proxy → 127.0.0.1:3333 → P2Pool
```

Повторное нажатие безопасно: если XMRig уже использует Proxy, запись config и restart не выполняются.

## 🟠 P2Pool Analytics

Расширенная статистика использует официальный P2Pool Data API.

Для неё P2Pool запускается с параметрами:

```text
--data-api /path/to/api --local-api
```

Панель автоматически определяет `--data-api` в аргументах работающего процесса и читает данные из Data API, включая:

- `local/stratum`;
- `pool/stats`;
- `network/stats`.

В интерфейсе доступны:

- local hashrate 15m / 1h / 24h;
- shares found / failed;
- current / average effort;
- miner connections;
- workers;
- pool hashrate;
- pool miners;
- найденные блоки;
- sidechain.

### Включение P2Pool Analytics в один клик

Если P2Pool работает без Data API, в **Сервер → Компоненты → P2Pool аналитика** появляется кнопка **«Включить P2Pool аналитику»**.

Панель:

1. определяет systemd unit, которому принадлежит P2Pool;
2. находит реальную команду запуска P2Pool в startup script или создаёт systemd drop-in;
3. игнорирует служебные строки вроде `pgrep`, `grep`, `echo`;
4. создаёт backup startup-файла;
5. добавляет `--data-api` и `--local-api` именно в команду запуска P2Pool;
6. проверяет shell script через `bash -n`;
7. перезапускает service;
8. ждёт появления нового P2Pool процесса с нужными flags;
9. при неудаче возвращает исходную конфигурацию и перезапускает сервис обратно.

Подробнее: [P2POOL.md](P2POOL.md).

## 🧠 Базовая норма хешрейта

Для каждого сервера панель изучает его собственный обычный 60s-hashrate. По умолчанию используется история примерно за 24 часа, нижняя нестабильная четверть замеров отбрасывается, а после достаточного количества образцов рассчитывается устойчивая базовая норма.

Это позволяет заметить деградацию конкретной машины даже тогда, когда XMRig остаётся online.

## ♻️ Auto-recovery и grace period

После запуска или restart сложного mining service XMRig может появиться значительно позже monerod и P2Pool. Grace period временно подавляет ложные алерты и автоматические restart.

Auto-recovery учитывает несколько последовательных неудачных проверок и cooldown, чтобы не создавать restart-loop.

## ⌨ SSH Terminal

Терминал открывается прямо из браузера через SSH-соединение панели. Поддерживаются пароль, private key и ssh-agent.

XMRig/Proxy API при этом не требуется открывать наружу.

## 🛡 Принцип безопасных one-click операций

Для действий, способных остановить майнинг, проект старается использовать общий подход:

```text
preflight → backup → изменение → restart → verification → rollback при ошибке
```

Это относится, в частности, к безопасному переключению XMRig через Proxy и включению P2Pool Analytics.
